Percentage input field. 1.6.9.

## When To Use

Use to enter percentages and ratios. Values are stored as decimals: for example, `0.0126` is displayed as `1.26%`.

Supports standalone input, DataSet binding, ranges and multiple values. Set the DataSet field type to `percentage`.
